# Odin Recipes
A simple recipe website built with HTML and CSS as part of The Odin Project foundations course.

## What I Learned
This project helped me practice:

* Basic HTML structure
* Working with links and images
* Relative file paths
* Using Git and GitHub for version control
* Working with the terminal and basic Linux commands
* CSS styling: box model, display types, selectors, fonts, colors
* Google Fonts integration
* CSS descendant selectors

The HTML part was straightforward, but the most valuable experience was becoming more familiar with Git, GitHub, and terminal workflow. CSS taught me how the box model works and how browsers render elements by default.

## Technologies Used

* HTML5
* CSS3
* Git
* GitHub
* Linux Terminal
